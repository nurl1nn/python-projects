# 💸 Personal Expense Tracker

A simple command-line expense tracking tool built with Python.

## Features

- Add expenses with amount, category, and date
- View all recorded expenses
- Calculate total expenses
- Save expenses to a CSV file

## Requirements

- Python 3.x
- No external libraries required

## Usage

Run the program:

```bash
python main.py
```

Follow the prompts:

```
Do you want to add an expense? Y/N: Y
Add money: 10
Add a category: Food
Add a date: 2024-01-01
```

When you are done adding expenses, press `N` to stop and view your summary.

## Example Output

```
-----All of your expenses-----
10 AZN | Food | 2024-01-01
5 AZN  | Transport | 2024-01-02
Your total expenses is: 15AZN
```
