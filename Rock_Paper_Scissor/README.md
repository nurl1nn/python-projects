# Rock Paper Scissors 🎮

A simple command-line Rock Paper Scissors game written in Python where you play against a bot.

## Features

- Play against a randomly choosing bot
- Input validation — invalid choices are rejected
- Play as many rounds as you want
- Clean win/lose/draw output after each round

## How to Play

1. Run the script
2. Type one of the following when prompted: `Rock`, `Paper`, or `Scissor`
3. The bot randomly picks its choice
4. The result is displayed: **Win**, **Lose**, or **Draw**
5. Choose `y` to play again or `n` to quit

## Example

```
Choose one of these: Rock , Paper, Scissor
Rock
Bot choose: Scissor
You choose: Rock
You win!
Do you want play again? y/n: n
Thanks for playing
```

## Game Rules

| You    | Bot     | Result |
|--------|---------|--------|
| Rock   | Scissor | Win ✅  |
| Paper  | Rock    | Win ✅  |
| Scissor| Paper   | Win ✅  |
| Same   | Same    | Draw 🤝 |
| Any    | other   | Lose ❌ |
